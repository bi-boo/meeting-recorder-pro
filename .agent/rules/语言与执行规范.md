# 语言与执行规范

## 一、语言与沟通规范

### 1. 语言规范
- **所有输出使用中文**：包括但不限于：对话回复、思考过程、任务清单、实施计划、完成总结、任务边界信息、代码注释（新写的代码）。
- **例外**：代码本身、变量名、函数名、报错信息等技术内容保持英文。
- **通俗化表达**：面向产品经理（无技术背景），使用**大白话**和**简单逻辑**解释，避免晦涩术语。

### 2. 执行与确认
- **自动解决依赖**：遇到缺失的环境或依赖，**直接安装**，无需询问或申请权限。
- **关键确认**：涉及**重要操作**、**不确定需求**或**模糊需求**时，必须先与用户**确认**后再执行。

### 3. 代码交付标准
- **免代码审查**：无需请求用户审查代码。
- **结果导向**：确保代码**无 Bug** 且功能正常。
- **关联修改**：修改一处代码时，务必检查并同步修改所有关联场景。

### 4. 开发环境
- **开发设备**：MacBook Pro 14寸 (M1 Pro)
- **浏览器**：Chrome
- **测试设备**：iPhone 和 Android 手机

### 5. 应用更新流程
- **Android 端**：手机连接电脑时，自动编译并覆盖安装。
- **PC 端**：代码更新后，自动重启应用。
