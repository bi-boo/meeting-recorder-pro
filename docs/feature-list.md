# 会议录音 Pro 功能清单

本文件记录当前公开版必须保持可用的功能。新增、删除或降级功能时，需要同步更新 README、PRD、架构文档、测试用例和分发说明。

## 核心录音

| 功能 | 状态 | 交付要求 |
|---|---|---|
| 麦克风录音 | 必须可用 | 生成可播放 M4A，48kHz 单声道，日志无写入失败 |
| 系统声音录音 | 必须可用 | 有屏幕录制权限时生成有效音频文件 |
| 麦克风 + 系统声音 | 必须可用 | 双路混合后生成有效音频文件 |
| 暂停/继续 | 必须可用 | 暂停期间不计入主要录音时长，继续后能保存 |
| 连续录音 | 必须可用 | 连续多次开始/停止，文件不覆盖 |
| 录音中退出保存 | 必须可用 | 退出前完成写入和必要的 MP3 转码 |
| 录音中断保存 | 必须可用 | 设备变化、系统音频异常、磁盘不足等场景自动保存并提示 |

## 输出与文件

| 功能 | 状态 | 交付要求 |
|---|---|---|
| M4A 输出 | 必须可用 | 默认输出，文件可播放 |
| MP3 输出 | 必须可用 | 先录 M4A，再用 LAME 分块转码；转码成功后删除源 M4A |
| 文件命名 | 必须可用 | 最终文件名为日期、星期、开始时间、时长；冲突自动追加序号 |
| 初始录音文件 | 内部能力 | `ing.m4a` 临时名必须唯一，不能覆盖旧文件 |
| 录音后打开文件夹 | 可选能力 | 用户开启后在 Finder 定位输出文件 |

## 定时计划

| 功能 | 状态 | 交付要求 |
|---|---|---|
| 单次计划 | 必须可用 | 到点触发后自动禁用 |
| 每天计划 | 必须可用 | 触发后顺延到下一天 |
| 每周计划 | 必须可用 | 支持周一到周日多选 |
| 自动录音 | 必须可用 | 到点自动开始录音并保存文件 |
| 提前提醒 | 必须可用 | 弹出提醒，用户确认后开始录音 |
| 时间冲突检测 | 必须可用 | 相同小时分钟不能保存两个计划 |
| 数量上限 | 必须可用 | 最多 6 个计划 |

## 设置与交互

| 功能 | 状态 | 交付要求 |
|---|---|---|
| 菜单栏常驻 | 必须可用 | 无 Dock 图标，菜单栏可打开菜单和设置 |
| 全局快捷键 | 必须可用 | 默认开始/结束为 `Control + Option + Command + 5`，暂停/继续为 `Control + Option + Command + 4` |
| 快捷键改绑 | 必须可用 | 新快捷键生效，冲突时不覆盖旧设置 |
| 录制来源选择 | 必须可用 | 麦克风、系统声音、混合三档 |
| 麦克风设备选择 | 必须可用 | 支持系统默认和可用物理麦克风 |
| 保存目录选择 | 必须可用 | 能选择目录，重启后保留 |
| 最长录音时长 | 必须可用 | 5 分钟到 9 小时 55 分钟 |
| 图标样式 | 可选能力 | 麦克风、指示点、波形图 |
| 显示录音时长 | 可选能力 | 菜单栏显示或隐藏计时 |
| 闲置图标变暗 | 可选能力 | 未录音时图标透明度降低 |
| 开机自动启动 | 必须可用 | UI 状态与 `SMAppService.mainApp.status` 一致 |

## 权限与系统行为

| 功能 | 状态 | 交付要求 |
|---|---|---|
| 麦克风权限 | 必须可用 | 未授权时给出系统设置引导 |
| 屏幕与系统音频录制权限 | 必须可用 | 仅选择系统音频相关模式时触发 |
| 录音期间防休眠 | 必须可用 | 录音中持有防休眠断言 |
| 有定时计划时防休眠 | 可选能力 | 有启用计划时按用户设置持有断言 |
| 日志 | 必须可用 | 写入 `~/Library/Application Support/Logs/MeetingRecorderPro_YYYY-MM-DD.log` |

## 分发能力

| 功能 | 状态 | 交付要求 |
|---|---|---|
| 开源许可 | 必须可用 | 根目录保留 MIT `LICENSE` |
| 第三方声明 | 必须可用 | 根目录保留 `THIRD_PARTY_NOTICES.md` |
| LAME 许可 | 必须可用 | 保留 `SimpleRecorder/ThirdParty/lame/COPYING`，DMG 根目录包含 `LAME-COPYING.txt` |
| 本机 DMG | 必须可用 | `./build_dmg.sh` 通过 |
| 正式 DMG | 发布前必须可用 | `RELEASE=1 ./build_dmg.sh` 通过 |
| 自动更新 | 必须可用 | Sparkle 每天检查 GitHub Releases appcast；录音中禁用检查；发布时同步上传 DMG 和 `appcast.xml` |
