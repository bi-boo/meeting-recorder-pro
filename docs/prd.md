# 会议录音 Pro - 产品需求文档

## 目标与背景

"会议录音 Pro"是一款专为 macOS 设计的高可靠、极简主义的录音工具。它通过常驻系统菜单栏的形式，解决了用户在会议、访谈或日常灵感捕获时对"快速开启、稳定录制、极致纯粹"的核心需求。本产品移除了所有臃肿的转写、总结及列表管理功能，专注于将录音做到极致。

---

# H1 录音控制与核心流程

## H2 触发阶段
1. **即时启动**：支持点击菜单栏按钮或按下全局快捷键立即开始。
2. **环境安全预检**：
   - **权限检查**：
     - **麦克风**：启动前验证麦克风访问权限。
     - **屏幕录制（系统音频）**：仅当用户在录制来源中选择"系统声音"或"同时录制"时才触发权限申请。首次启动应用时不请求。
   - **磁盘检查**：录音前执行可用空间预检。最低要求为 100MB；实际门槛会按当前最长录音时长和输出格式动态估算。空间不足时弹出“磁盘空间不足”提示，并显示当前所需的最小可用空间。
   - **写入预检**：确保存储目录具备写入权限。

## H2 录制阶段
1. **录制状态反馈**：
   - **图标显示**：状态栏显示当前所选样式，不额外着色，遵循系统黑白主题。
   - **计时器**：始终显示 `mm:ss` 格式的累计计时。分钟数支持三位（例如 `120:30`），不会因时长超过一小时而切换至 `HH:mm:ss` 格式。
   - **锁定机制**：录制过程中，禁止切换“录制来源”和“麦克风设备”。设置界面将同步显示提示文案：“**录音中，设置将在下次录音时生效**”。
2. **实时操作控制**：
   - **暂停/继续**：支持在录音中途暂停，累计时长**不包含**暂停的时间。
   - **防休眠机制**：录音期间自动激活系统电源断言，防止 Mac 进入闲置休眠。
3. **高可靠写入架构**：
   - **Fragmented MP4 (fMP4)**：采用流式存储技术，崩溃后文件依然可播。
4. **录音中断检测与提醒**：
   - **监测场景**：设备插拔（耳机、USB 麦克风、蓝牙设备）、当前设备断开、音频引擎配置变更、系统音频采集异常、磁盘空间不足、写入器失败。
   - **处理逻辑**：检测到异常后自动保存已录制内容，弹窗告知用户中断原因。
   - **弹窗按钮**：「再次开始录音」和「知道了」两个操作。

## H2 结束阶段
1. **文件自动重命名**：
   - **命名规约**：格式为 `年.月.日  星期  时.分 - 时长min.m4a`（例如 `2026.01.24  Sat  18.09 - 13min.m4a`）。
   - **冲突处理**：若文件名重复，自动在末尾追加 `(1)`, `(2)` 序号。
2. **后续自动化动作**：
   - **定位 Finder**：录音结束后自动在文件夹中高亮选定该文件。
   - **MP3 转换**：选择 MP3 时，先保存 M4A，再异步分块转码为 MP3；成功后删除原 M4A。

# H1 基础设置 (Basic Settings)

## H2 全局快捷键
1. **核心功能**：支持为以下两个动作设置独立快捷键：
   - **开始/结束录音**（默认：`Control + Option + Command + 5`）
   - **暂停/继续录音**（默认：`Control + Option + Command + 4`）
2. **按键支持范围**：
   - **字符键**：A-Z, 0-9。
   - **功能键**：F1-F12。
   - **特殊键**：空格、回车。
   - **约束**：必须包含修饰键（Cmd/Shift/Opt/Ctrl）中的至少一种。
3. **冲突检测**：若设置的快捷键已被另一个功能占用，将显示 Alert 弹窗。
   - **标题**：快捷键冲突
   - **内容**：该快捷键已被其他功能使用，请选择不同的快捷键。

## H2 录制来源
1. **可选内容**：
   - **仅麦克风**：采集硬件输入。
   - **仅系统声音**：捕获内部音频流。
   - **麦克风 + 系统声音**：混合双路音频，采样率对齐。
2. **设备管理**：支持实时切换已连接的物理麦克风。

## H2 存储管理
1. **存储路径**：显示当前的绝对路径，支持 Security-Scoped Bookmark 持久化权限。
2. **交互动作**：
   - 「**更改...**」：调起系统文件夹选择器。
   - 「**在 Finder 中打开**」：直接在窗口中打开当前所选的录音目录。
3. **选项**：提供“录音完成后自动打开文件夹”开关。

# H1 定时计划 (Timer Tasks)

## H2 计划管理
1. **重复模式**：
   - **不循环**（默认）：触发一次后自动禁用。
   - **每天**：每 24 小时循环。
   - **每周**：支持周一至周日的多选循环。
2. **时间精度与排序**：
   - 支持 1 分钟档位的时间精度设置。
   - **排序规则**：列表按设定时间的绝对时间（0-24点）进行升序排列，不区分启用状态。
3. **容量与唯一性限制**：
   - **数量上限**：最多允许设置 **6** 个定时计划。
   - **时间唯一性**：相同时间点仅允许存在一个计划，保存时执行冲突检查。

## H2 触发方式
1. **默认设置**：新计划默认采用“**自动录音**”方式。
2. **表现形式**：
   - **提前提醒**：标题「**是否启动录音**」，副标题「**计划时间 HH:mm**」。提供「忽略」和「开始录音」按钮，120s 无操作自动失效。
   - **自动录音**：标题「**录音已开始**」，副标题「**计划时间 HH:mm**」。弹窗停留 5s 后自动消失。
3. **视觉展示**：在计划列表中，提醒方式以黑色/灰色的小标签形式显示在循环描述后面（如 `每周一至周五 · 自动录音`）。

## H2 系统控制 (集成的全局开关)
此部分开关位于定时计划页面下方，用于统筹系统行为：
1. **开机自动启动**：控制应用是否随系统登录启动。
2. **录音时禁止系统睡眠**：**强制开启**且不可关闭。录音状态下通过电源断言确保录制不中断。
3. **有定时计划时禁止系统睡眠**：默认开启。若当前存在**已启用**的计划且开启此项，应用将阻止系统进入待机休眠，确保计划能被唤醒触发。

# H1 高级设置 (Advanced Settings)

## H2 录制进阶
1. **时长上限**：小时 (0-9) + 分钟 (0-55, 5分钟步进)，范围为 5 分钟至 9 小时 55 分钟。
2. **保存格式选择**：
   - **M4A 模式**：原生高效编码，逻辑上直接重命名临时文件。
   - **MP3 模式**：录音结束后自动触发 LAME 分块转码，避免长录音转码时内存暴涨。

## H2 视觉策略 (Visual Strategy)
1. **图标样式切换**：支持“麦克风”、“指示点”、“波形图”三态切换。
2. **显示时长控制**：允许在菜单栏隐藏实时计时数字，仅保留图标。
3. **闲置图标变暗**：若开启此项，未录音状态下菜单栏图标透明度降至 **0.35**。

## H2 自动更新
1. **入口**：菜单栏提供“检查更新...”入口。
2. **后台检查**：应用每天检查一次 GitHub Releases 更新源；无更新时保持默认文案。
3. **发现更新**：操作项显示“下载并安装 x.y.z...”，不主动弹出更新窗口。
4. **用户安装**：用户点击可用更新后，不展示更新窗口和版本说明，直接进入下载、验签、重启安装流程。
5. **过程反馈**：菜单内显示“当前版本 x.y.z”和更新流程状态；重启后确认安装成功时显示“已更新到 x.y.z”。
6. **录音保护**：录音中禁用更新检查，避免安装流程影响录音保存。

# H1 关于会议录音 Pro (About)

## H2 视觉展示
- **应用图标**：采用由 `logo.jpeg` 生成的专属产品图标。
- **关于界面**：移除产品 Logo 展示，采用极简纯文字风格排版。

## H2 产品核心特性定义（官方文案）
1. **实时保存**：录音过程中，文件循环保存。即使电脑突然断电、应用意外崩溃或被强制退出，已录制的内容都不会丢失。
2. **防止休眠**：录音期间自动阻止系统进入休眠状态。即使合上笔记本，录音也能在后台继续进行，适合需要长时间录音的场景。
3. **全局快捷键**：无论在使用什么应用程序，只需按下预设的快捷键，即可立即开始或结束录音，无需切换窗口。
4. **双向录音**：支持同时录制麦克风输入和系统内部声音。戴着耳机参加线上会议时，也能完整录下对方的发言和你自己的声音。
5. **定时录音**：支持设置周期性定时计划，到点自动录音或提前弹窗提醒。再也不用担心忙碌时忘记开启录音，轻松捕捉每一场重要会议。
